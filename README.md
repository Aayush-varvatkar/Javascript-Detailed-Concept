## 📌 Repository Overview

This repository is structured to guide developers through the core foundations of modern JavaScript up to advanced browser DOM/BOM manipulation. It includes working `.js` logic files and interactive `.html` demonstrations.

### 🌟 Core Learning Modules
- 🧱 **Variables & Scope**: `var` vs `let` vs `const`, primitive data types vs objects.
- 🔀 **Control Flow & Logic**: Conditional statements, operators, template literals, and input dialogs.
- 📦 **Array & String Operations**: Array iteration, string immutability, and built-in methods.
- 🔄 **Higher-Order Functions**: Functional programming with `map()`, `filter()`, `reduce()`, and callback execution.
- 🌐 **DOM & BOM Manipulation**: Traversing children, element creation, query selectors, style manipulation, and attribute getter/setters.
- ⚡ **Event Handling**: Event listeners, dynamic UI interactions, and console object methods.
- 🧩 **Interactive Practice Exercises**: Mini Calculator, Number Guessing Game, and algorithmic practice sets.

## ⚡ Key Concepts Quick Reference

### 🧠 Scope Matrix: `var` vs `let` vs `const`
| Feature | `var` | `let` | `const` |
| :--- | :---: | :---: | :---: |
| **Scope** | Function / Global | Block (`{}`) | Block (`{}`) |
| **Re-declaration** | Allowed | Not Allowed | Not Allowed |
| **Re-assignment** | Allowed | Allowed | Not Allowed |
| **Hoisting** | Hoisted (Initialized `undefined`) | Hoisted (Temporal Dead Zone) | Hoisted (Temporal Dead Zone) |

### 🎯 Higher-Order Array Methods Cheat Sheet
```javascript
// 1. map() - Creates a new array by transforming every element
const numbers = [1, 2, 3, 4];
const doubled = numbers.map(x => x * 2); // [2, 4, 6, 8]

// 2. filter() - Creates a new array with elements that pass a test
const evens = numbers.filter(x => x % 2 === 0); // [2, 4]

// 3. reduce() - Reduces an array to a single value
const sum = numbers.reduce((acc, curr) => acc + curr, 0); // 10
```
